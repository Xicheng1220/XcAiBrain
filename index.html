AI Brain

AI Brain is a personal, single-user desktop tool. It stores short summaries of the owner's own work notes in the owner's own Google Drive, so the owner's computers can share them.

AI大脑是一个个人自用的桌面工具，把本人的工作笔记摘要存进本人自己的 Google 云盘，供本人的多台电脑共享。

  • Scope used: drive.file only — the app can see only files it created itself.
  • No server. No data is sent anywhere except the owner's own Google Drive.
