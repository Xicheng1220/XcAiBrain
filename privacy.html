Privacy Policy · 隐私政策

Last updated: 2026-10-29

What the app accesses

AI Brain requests only the https://www.googleapis.com/auth/drive.file scope. It can read and write only the files and folders it created in the user's Google Drive. It cannot see any other files.

Where data goes

All data stays in the user's own Google Drive. The app has no server and does not collect, sell, share, or transfer any user data to third parties. The OAuth token is stored only on the user's own computer.

Google API Services User Data Policy

AI Brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Remove access at any time at https://myaccount.google.com/connections .
